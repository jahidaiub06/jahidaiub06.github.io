# Jahidul Islam Website

Static personal research website.

## Files

- `index.html` - main website
- `styles.css` - responsive styling
- `script.js` - navigation and scroll interactions
- `project-portfolio/` - separate project portfolio page
- `assets/profile-photo.jpg` - portrait photo
- `assets/research-hero.png` - hero image
- `assets/logos/` - institution logo assets
- `assets/icons/` - contact and profile icons
- `JAHIDUL_ISLAM_CV.pdf` - CV

## GitHub Pages Deployment

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to `Settings > Pages`.
4. Select `Deploy from a branch`.
5. Choose `main` branch and `/root`.
6. Save and wait for GitHub to publish the link.

The public URL will look like:

```text
https://your-username.github.io/repository-name/
```
